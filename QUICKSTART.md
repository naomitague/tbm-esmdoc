# Quick Start

Get the site running locally.

## Prerequisites
- [Node.js](https://nodejs.org/) 20 or later
- [pnpm](https://pnpm.io/installation) (`npm install -g pnpm`, or use corepack: `corepack enable`)

## Run it
```bash
pnpm install
pnpm dev
```
Then open [http://localhost:3000](http://localhost:3000).

## Production build
```bash
pnpm build
pnpm start
```

For everything else — project structure, content conventions, how the
CSV-backed tables/charts work, how to add new content — see `CLAUDE.md`.
