# Whittaker Biome Classification (Biome)

|Biome|Approx. Temp Range|Approx. Precip Range|Typical Vegetation|
|---|---|---|---|
|Tropical rainforest|Warm, high|Very high (>2000mm)|Dense broadleaf evergreen forest|
|Tropical seasonal forest / savanna|Warm|Moderate–high, seasonal|Deciduous/mixed forest, grassland with trees|
|Subtropical desert|Hot|Very low (<250mm)|Sparse xerophytic shrubs, succulents|
|Temperate grassland / desert|Moderate|Low–moderate|Grasses, shrubs|
|Temperate seasonal forest|Moderate|Moderate–high|Broadleaf deciduous forest|
|Temperate rainforest|Cool–moderate|High|Coniferous/broadleaf evergreen forest|
|Woodland / shrubland|Moderate–warm|Low–moderate, seasonal|Sclerophyllous shrubs, scattered trees (chaparral-type)|
|Boreal forest (taiga)|Cold|Low–moderate|Coniferous evergreen forest|
|Tundra|Very cold|Low|Low shrubs, mosses, lichens, no trees|

> Note: Whittaker's biome scheme is defined by a temperature–precipitation biplot rather than fixed numeric bins, so exact cutoffs vary by source — worth flagging in this reference note if using it to classify the unmatched Zhang rows.
